🔊 ESP Audio Dock Firmware Installer View on GitHub

Flash and provision ESP Audio Dock boards from your browser

No local toolchain, no dashboard - plug the board in over USB and click Install below.

1. Connect
Plug the device into your computer with a USB cable, then click an Install button on the board you have.
2. Provision Wi-Fi
ESPHome images ask for Wi-Fi credentials right in the browser (Improv) during setup - no secrets baked into the firmware. Squeezelite-ESP32 images use the same connect button to set up Improv-serial Wi-Fi on already-flashed devices.
3. Stay updated
ESPHome images check GitHub Pages for new firmware automatically; no need to reflash for future updates.

On Linux you may need to add your user to the dialout group (or adjust permissions on /dev/ttyUSBX) for the browser to see the device. Installing requires Chrome, Edge, or another browser with Web Serial support. For Squeezelite-ESP32, the 16-bit build is recommended for most boards - see the readme for details.

AirPlay and standalone Snapcast aren't built from this repo, so they live on their own installer pages - browser-flashable too, just hop over to install them.

AirPlay 1 & 2

A standalone AirPlay 1 & 2 receiver from rbouteiller/airplay-esp32 - appears natively in Control Center with PTP-based multi-room sync. Also bundles the experimental Sendspin renderer and, on classic ESP32 boards, Bluetooth A2DP.

  • Supports HiFi-ESP32, Loud-ESP32, Louder-ESP32, Louder-ESP32-Plus, and Amped-ESP32 today (both ESP32 / ESP32-S3)
  • Not yet available for HiFi/Amped-ESP32-Plus, Louder-ESP32-mini/Pro, or Loud-ESP32-Plus - see the readme for the current roadmap
  • Full 15-band parametric EQ + crossover control on Louder-ESP32 and Louder-ESP32-Plus

Standalone Snapclient

A Snapcast client build maintained by sonocotta/esparagus-snapclient (built on CarlosDerSeher/snapclient) for perfectly synchronized multi-room playback, independent of the ESPHome/Squeezelite builds above.

  • Zero configuration - auto-discovers your Snapcast server (Music Assistant, a Raspberry Pi, etc.)
  • Available for every ESP32 Audio Dock board
  • Pick classic ESP32 over S3 for now - S3 support is still in beta and noticeably laggier
